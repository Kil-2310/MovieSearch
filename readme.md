Тема проекта "Поиск фильмов"

API - https://poiskkino.dev/

Необходимо разработать телеграм-бота, который будет взаимодействовать с API фильмов и выполнять определённые команды:
● movie_search - поиск фильма/сериала по названию;
● movie_by_rating - поиск фильмов/сериалов по рейтингу;
● movie_by_budget - поиск фильмов/сериалов по бюджету;
● deep_search - поиск тайтлов по бюджету и рейтингу;
● get_random_movie - получение рандомного тайтла;
● help - вывести спавку;
● start - запуск бота.

В вывод каждого фильма/сериала должны быть включены:
● название,
● описание,
● рейтинг,
● год производства,
● жанр,
● постер.
