Тема проекта "Поиск фильмов"

API - https://poiskkino.dev/

Необходимо разработать телеграм-бота с подключением к базе данных (далее - БД) - SQLite, который будет взаимодействовать с API фильмов и выполнять определённые команды:
● ask_giga_chat - команда для взаимодействия с нейросктью;
● movie_search — поиск фильма/сериала по названию;
● movie_by_rating — поиск фильмов/сериалов по рейтингу;
● budget_movie — поиск фильмов/сериалов по бюджету;
● history — возможность просмотра истории запросов и поиска фильма/сериала;
● get_viewed_movies - получить список просмотренных фильмов;
● add_to_viewed_movies - добавить в список просмотренных фильмов;
● get_random_movie - получение рандомного тайтла.

В сценарий поиска должны быть включены следующие вопросы:
● название;
● жанр(комедия, ужасы, фантастика и так далее);
● количество выводимых вариантов.

В вывод каждого фильма/сериала должны быть включены:
● название,
● описание,
● рейтинг,
● годпроизводства,
● жанр,
● возрастной рейтинг,
● постер (ссылка).

В вывод истории запросов должны быть включены:
● дата поиска,
● название фильма/сериала,
● описание фильма/сериала,
● рейтинг,
● годпроизводства,
● жанр,
● возрастной рейтинг,
● постер (ссылка).

БД будет состоять из 4 таблиц:
1. Users - все пользователи бота
 - id - PK
 - username
 - first_name
 - last_name

2. User_Films - фильмы пользователя
 - id - PK
 - user_id - FK на Users
 - movie_id - FK на Requested_movies
 - is_viewed

3. User_History - история запросов пользователя
 - id - PK
 - user_id - FK на Users
 - command_name
 - request_date
 - movie_id - FK на Requested_movies

4. Requested_Movies - все запрошенные фильмы пользователя
 - id - PK
 - movie_name
 - id_movie_genre - FK на Movie_Genres
 - movie_description
 - movie_rating
 - movie_url_poster
 - movie_age_rating
 - api_movie_id

5. Movie_Genres - жанры фильмов
 - id - PK
 - name_genre

Помимо всего перечисленного, также будут доступны функции для улучшения пользовательского опыта UX и UI: при запросе истории бот будет уточнять, за какую дату показывать историю, пагинация, индексы в БД, получение просмотренных фильмов пользователя, перезагрузка бота (сброс всех состояний), развертывание бота на сервере time web и другие функции.
