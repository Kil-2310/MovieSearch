# Телеграмм бот "MovieSearch"

## О проекте

Телеграмм бот для поиска и фильтрации фильмов и сериалов, взаимодействующий с внешни API: https://poiskkino.dev/

В связи с особенностями работы интернет-сервисов на территории Российской Федерации, стабильность функционирования Telegram-бота может зависеть от текущей доступности внешних API и сетевых ограничений.

#### Ключевые возможности

    * Поиск по точному имени.
    * Поиск фильмов/сериалов по названию, рейтингу, бюджету.
    * Многоуровневый поиск по все критериям.
    * Получение рандомного фильма/сериала.

## Технологический стек

    * Python 3.10+ — интерпретируемый язык программирования.
    * Requests — легковесная HTTP-библиотека для отправки запросов к внешним API и получения данных.
    * Pydantic — библиотека для валидации данных и парсинга JSON с использованием типизации Python.
    * pyTelegramBotAPI — синхронная библиотека-обертка над Telegram Bot API для быстрой разработки ботов.
