# Телеграмм бот "MovieSearch"

## О проекте

Телеграмм бот для поиска фильмов 

#### Ключевые возможности

    * Поиск по точному имени
    * Поиск фильмов/сериалов по названию, рейтингу, бюджету
    * Многоуровневый поиск по все критериям
    * Получение рандомного фильма/сериала

## Технологический стек

    * Python 3.10+ - язык программирования
    * Requests
    * Pydantic
    * python-telegram-bot
    * pyTelegramBotAPI
    * Docker - контейнеризация приложения
