# Телеграмм бот "MovieSearch"

## О проекте

Телеграмм бот для поиска и фильтрации фильмов и сериалов, взаимодействующий с внешни API: https://poiskkino.dev/

В связи с особенностями работы интернет-сервисов на территории Российской Федерации, стабильность функционирования Telegram-бота может зависеть от текущей доступности внешних API и сетевых ограничений. Рекомендуется использовать VPN-соединение или запускать бота на сервере за пределами РФ для гарантированной бесперебойной работы.

#### Ключевые возможности

    * Поиск по точному имени.
    * Поиск фильмов/сериалов по названию, рейтингу, бюджету.
    * Многоуровневый поиск по все критериям.
    * Получение рандомного фильма/сериала.

## Технологический стек

    * Python 3.10+ — интерпретируемый язык программирования.
    * Requests — легковесная HTTP-библиотека для отправки запросов к внешним API и получения данных.
    * Pydantic — библиотека для валидации данных и парсинга JSON с использованием типизации Python.
    * pyTelegramBotAPI — синхронная библиотека-обертка над Telegram Bot API для быстрой разработки ботов.
    * Docker — платформа для контейнеризации, обеспечивающая изолированное и воспроизводимое окружение приложения.

### Перед запуском проекта необходимо:

Установить Docker, по ссылке: https://docs.docker.com/engine/install/. Получить токен бота от BotFather. Заполнить .env файл в корне проекта, по примеру, указанному ниже:

    BOT_TOKEN='8228315371:BAF9PiqUBEhjgUTU4VpQbS6LL0LkARGGS7M'
    API_TOKEN='RR6BNFX-2YC4D1N-HWEZZ72-OFJRKAH'

### Сборка, запуск и остановка проекта

``` bash
docker build -t moviesbot .
docker run -d --network host --name moviesbot_container moviesbot
docker stop moviesbot_container
```
